# Personal Resume

This is a personal resume template built with HTML and CSS, designed to be easily hosted on GitHub Pages.

## How to use this template

1. Open `index.html` and replace all the placeholder text (enclosed in brackets like `[Your Name]`) with your actual information.
2. Edit the skills, experience, and education sections to match your background.
3. If desired, open `style.css` to tweak the colors, fonts, or layout.

## Deploying to GitHub Pages

1. Initialize a Git repository in this folder, commit your files, and push them to a new repository on GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/[your-username]/[your-repo-name].git
   git push -u origin main
   ```
2. Go to your repository on GitHub.
3. Click on **Settings** > **Pages** (in the left sidebar).
4. Under the **Build and deployment** section, select **Deploy from a branch**.
5. Under **Branch**, select `main` (or `master`) and keep the folder as `/(root)`.
6. Click **Save**. 

Within a minute or two, your website will be live at `https://[your-username].github.io/[your-repo-name]/`!
